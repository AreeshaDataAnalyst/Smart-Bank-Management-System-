# Smart-Bank-Management-System-
Bank Management System using Python, SQLite and File Handling
A Python-based Bank Management System using SQLite and File Handling.

## Features
- Create Bank Account
- Check Balance
- Deposit Money
- Withdraw Money
- Transaction History
- View All Accounts

## Technologies Used
- Python
- SQLite3 Database
- File Handling

## Project Structure
- Bank_Management_system.py → Main program
- bank.db → SQLite database
- accounts.txt → Account records
- balance.txt → Updated balances
- transactions.txt → Transaction history
